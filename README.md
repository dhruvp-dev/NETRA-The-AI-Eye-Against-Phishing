## Dataset Download Instructions

### 1. Enron Email Dataset (Legitimate — label=0)

**Option A — Kaggle**
- Dataset: `wcukierski/enron-email-dataset`
- URL: https://www.kaggle.com/datasets/wcukierski/enron-email-dataset
- Format: CSV with `message` column (or extract mbox per user folder)
- Download: `kaggle datasets download -d wcukierski/enron-email-dataset`
- Place as: `data/raw/enron_emails.csv` or `data/raw/enron_*.mbox`

**Option B — CMU Direct**
- URL: https://www.cs.cmu.edu/~enron/enron_mail_20150507.tar.gz
- ~432 MB compressed, contains per-user mbox files

**Label to assign**: `0` (legitimate)

---

### 2. Nazario Phishing Email Corpus (Phishing — label=1)

- GitHub: https://github.com/andymcdgeo/andymcdgeo-datasets (search "nazario phishing")
- Kaggle: https://www.kaggle.com/datasets/rtatman/fraudulent-email-corpus
  ```
  kaggle datasets download -d rtatman/fraudulent-email-corpus
  ```
- Alternate (direct mbox): http://monkey.org/~jose/phishing/phishing3.mbox
- Format: CSV with columns `body`, `subject` (varies by source)
- Place as: `data/raw/nazario_phishing.csv`

**Label to assign**: `1` (phishing)

---

### 3. SpamAssassin Public Corpus (Ham=0, Spam=1)

- URL: https://spamassassin.apache.org/old/publiccorpus/
- Download these specific files:
  ```
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_easy_ham.tar.bz2
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_hard_ham.tar.bz2
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_spam.tar.bz2
  wget https://spamassassin.apache.org/old/publiccorpus/20030228_spam_2.tar.bz2
  ```
- Format: Individual `.eml` files in tar.bz2 archives → convert to mbox or parse directly
- Place as: `data/raw/easy_ham.mbox`, `data/raw/spam_2.mbox` etc.

**Label to assign**: Ham → `0`, Spam → `1`

---

### 4. PhishTank URL Feed (Phishing — label=1)

- URL: https://data.phishtank.com/data/online-valid.csv.bz2
- Direct download (free, no account required):
  ```
  wget https://data.phishtank.com/data/online-valid.csv.bz2
  bunzip2 online-valid.csv.bz2
  ```
- Format: CSV with columns: `url, phish_detail_url, submission_time, verified, verification_time, online, target`
- Place as: `data/raw/phishtank_online_valid.csv`

**Label to assign**: `1` (phishing)

---

### 5. OpenPhish Feed (Phishing — label=1)

- URL: https://openphish.com/feed.txt
- Free community feed, updated every ~6 hours
  ```
  wget https://openphish.com/feed.txt -O data/raw/openphish_feed.txt
  ```
- Format: Plain text, one URL per line
- Place as: `data/raw/openphish_feed.txt`

**Label to assign**: `1` (phishing)

## What To Do Next

### Step 1 — Download Datasets
```bash
# PhishTank (no auth needed)
wget https://data.phishtank.com/data/online-valid.csv.bz2 -O data/raw/phishtank_online_valid.csv.bz2
cd data/raw && bunzip2 phishtank_online_valid.csv.bz2 && cd ../..

# OpenPhish
wget https://openphish.com/feed.txt -O data/raw/openphish_feed.txt

# SpamAssassin
wget https://spamassassin.apache.org/old/publiccorpus/20030228_easy_ham.tar.bz2 -P data/raw/
wget https://spamassassin.apache.org/old/publiccorpus/20030228_spam_2.tar.bz2 -P data/raw/

# Enron — via Kaggle CLI
kaggle datasets download -d wcukierski/enron-email-dataset -p data/raw/ --unzip

# Nazario — via Kaggle
kaggle datasets download -d rtatman/fraudulent-email-corpus -p data/raw/ --unzip
```

### Step 2 — Run the Colab Notebook
1. Upload entire `NETRA` folder to Google Drive under `My Drive/NETRA/`
2. Open `notebooks/NETRA_IPDS_Training.ipynb` in Google Colab
3. Run cells 1 → 6 in order
4. After Cell 6, download `tier1_model.pkl` and `tfidf_vectorizer.pkl` from Drive

### Step 3 — Start the FastAPI Server (Local Machine)
```bash
# Install requirements
pip install -r requirements.txt

# Place .pkl files in ml/models/
# Then start the server:
uvicorn api.main:app --host 127.0.0.1 --port 8000
```

### Step 4 — Test with curl
